FIND THE PROBLEM TRANSITION
4 Transitions to check:
T1: home → add_to_bag
T2: add_to_bag → cart
T3: cart → proceed_to_pay
T4: proceed_to_pay → charged
For each transition:
# Today
rate_today = next_stage_users_D / prev_stage_users_D

# Baseline (average over 7 days)
baseline_rate = mean([next_users_i / prev_users_i for each baseline day])

# Drop metrics
delta_rate = baseline_rate - rate_today
drop_pct = (delta_rate / baseline_rate) * 100
impact = delta_rate * prev_stage_users_D

Is this transition broken?
YES if: prev_stage_users_D >= 50 AND (delta_rate >= 0.03 OR drop_pct >= 10%)
NO otherwise
Pick winner: Highest impact among broken transitions
If nothing is broken → status: "no_significant_drop"
